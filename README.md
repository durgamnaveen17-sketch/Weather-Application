# React Weather Application

A weather application built with React and Vite using the OpenWeatherMap API.

## Features
- Search weather by city
- Display temperature
- Show humidity and wind speed
- Display weather icons
- Responsive user interface

## Technologies
- React
- JavaScript
- CSS
- Vite
- OpenWeatherMap API

## Installation

Clone the repository:

    git clone https://github.com/durgamnaveen17-sketch/Weather-Application.git

Navigate to the application folder:

    cd "Weather-Application/Weather Application"

Install dependencies:

    npm install

Create a .env file in the application folder:

    VITE_APP_ID=YOUR_OPENWEATHERMAP_API_KEY

Start the application:

    npm run dev
