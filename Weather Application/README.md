# 🌦️ React Weather Application

A responsive weather application built using **React.js** and **Vite** that fetches real-time weather information using the OpenWeatherMap API.

## 🚀 Features

- 🔍 Search weather by city name
- 🌡️ Display current temperature in Celsius
- 💧 Show humidity levels
- 💨 Display wind speed
- ☁️ Dynamic weather icons
- ⚠️ Loading indicators and error handling
- 📱 Responsive user interface

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- Vite
- OpenWeatherMap API
- Git and GitHub

## ⚙️ Installation and Setup

1. Clone this repository:

   ```bash
   git clone https://github.com/durgamnaveen17-sketch/Weather-Application.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Weather-Application
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Create a `.env` file in the project root and add your OpenWeatherMap API key:

   ```env
   VITE_APP_ID=YOUR_OPENWEATHERMAP_API_KEY
   ```

5. Start the development server:

   ```bash
   npm run dev
   ```

6. Open the local URL displayed in your terminal.

## 🔑 API Configuration

This application uses the OpenWeatherMap Current Weather API.

Get an API key from [OpenWeatherMap](https://openweathermap.org/api).

**Important:** Never commit your `.env` file or expose your API key in a public repository.
